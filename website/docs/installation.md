# התקנת גרסת הבדיקה

הגרסה 15.3.1-beta.4 אינה שחרור יציב. התקנה ועדכון מ־beta.1 ל־beta.2 אושרו על ידי המשתמש ואומתו בדפי Google. תיקוני beta.3 עברו בדיקות מקומיות; בדיקות הפרדת מספר חשבונות וכל סוגי הנתונים עדיין ממתינות.

1. התקינו Tampermonkey דרך [האתר הרשמי](https://www.tampermonkey.net/) וחנות הדפדפן.
2. פעלו לפי [הנחיות הרשאת Userscripts](https://www.tampermonkey.net/faq.php#Q209). Chrome עשוי לדרוש Allow User Scripts בפרטי התוסף או מצב מפתח בהתאם לגרסה. שמות האפשרויות משתנים; המקור הרשמי הוא הקובע.
3. פתחו את [קישור התקנת גרסת הבטא](https://raw.githubusercontent.com/moishyf/chat-studio-prozi-userscript/main/dist/chat-studio.user.js). אם Tampermonkey אינו פותח התקנה, העתיקו את הקובץ לעורך הסקריפט ושמרו. בעדכון יש להחליף את הסקריפט הקיים ולא ליצור עותק נוסף.
4. כבו את Chat Studio המקורי לפני הבדיקה. אין להסירו לפני גיבוי אם ברצונכם להעביר הגדרות.
5. רעננו Google Chat או Gmail ולחצו על פלטת הצבעים ליד שורת הכתיבה. לאחר כמה שניות עשוי להופיע כפתור צף אם סרגל הכתיבה לא נמצא.
6. בדקו בחירת עיצוב ושמירה לאחר רענון. לאחר מכן בדקו פרופיל אישי ורקע תמונה.

בקשות רשת מיוחדות מוגבלות ל־accounts.google.com לזיהוי חשבונות. קישורי תמונות אישיים נטענים מהאתר שבחרתם. התמונות המקומיות והרקעים המובנים אינם דורשים שירות חיצוני.

אין צילומי התקנה מאומתים כרגע: כלי הדפדפן חסם גישה ל־chrome://extensions. צילומי המוצר בתיעוד נלקחו מסביבת fixture בלבד.

`document-start` אינו מבטיח היעדר הבהוב. לפני שחרור יציב צריך לבדוק את הגדרת Content Script API ואת ההרצה המוקדמת לפי [תיעוד Tampermonkey](https://www.tampermonkey.net/documentation.php), ברענון קר וחם.
