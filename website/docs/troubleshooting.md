# פתרון תקלות

- אין כפתור: ודאו שהסקריפט פעיל, הרשאת Userscripts זמינה, ושאתם באתר Google Chat או Gmail. רעננו והמתינו לכפתור הצף. about:blank/srcdoc טרם אומתו.
- שני כפתורים או מראה כפול: כבו את התוסף המקורי או עותק userscript נוסף ורעננו.
- עיצוב אישי לא מופעל: בדקו שכתובת החשבון מזוהה בהגדרות. בלי זהות ודאית מוצג העיצוב הכללי. אינדקס u/0 אינו מזהה אדם קבוע.
- תמונה מקישור אינה נטענת: ייתכן שהקישור דורש התחברות או נחסם ב־CSP. נסו העלאה מקומית של קובץ נתמך.
- הודעת שמירה נכשלה: ייצאו גיבוי ככל האפשר, פנו מקום באחסון ונסו לשמור מחדש. אל תניחו ששינוי נשמר לאחר הודעת הכשל.
- עדכון אינו מגיע: המאגר כרגע פרטי וגרסת הבדיקה אינה ערוץ הפצה ציבורי. לאחר פרסום, בדקו את הגדרות העדכון של Tampermonkey; אין הבטחת עדכון מיידי.
- תפריט עדיין מוסתר: ציינו עיצוב, סוג חלונית, דפדפן והקשר Chat/Gmail. צילום חייב להיות נקי מתוכן פרטי. בדיקת fixture אינה מכסה כל מבנה DOM של Google.

להחזרת המראה הרגיל: כבו את הסקריפט ורעננו. לפיתוח: ראו TEST_REPORT.md עם רשימת המקרים שלא אומתו.
