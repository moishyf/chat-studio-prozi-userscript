# עדכונים

הזהות הקבועה היא Chat Studio · Prozi ו־namespace של המאגר. @updateURL ו־@downloadURL מפנים לקובצי dist בענף main, ללא תג גרסה קבוע. הם קיימים בתוצר אך אינם נגישים להפצה אנונימית כל עוד המאגר פרטי.

העורך מעלה מספר גרסה ב־package.json, בונה, בודק ומעלה את הקוד והתוצרים יחד. לאחר אימות CI ובדיקות הדפדפן אפשר להפעיל את workflow השחרור. המשתמשים מקבלים עדכון לפי תזמון והגדרות Tampermonkey.

בדיקת חובה לפני פתיחת הערוץ: התקינו גרסה A, שמרו פרופילים, תמונה ומועדף, פרסמו B עם אותה זהות, בצעו בדיקת עדכון ב־Tampermonkey וודאו שהסקריפט התעדכן ללא כפילות ושהמידע נשמר. בדיקה זו טרם בוצעה כאן. בדיקות היחידה מאמתות רק התאמת מטא־דאטה וקיום כתובות יציבות.
