דוח בדיקות — 15.3.1-beta.4

תיקון beta.4

כרטיס המגיבים החי זוהה כ־.qLAxZc[jsname=RxHuXc] ללא role. הוא נמצא ברשימת תגובות אחות לבועה, עם z-index:10 מול 60 של הבועה. נוסף זיהוי ממוקד שלו למנגנון השכבות. 21/21 בדיקות דפדפן עברו, כולל בדיקת elementFromPoint המאמתת שהכרטיס מצויר מעל הבועה וניקוי שכבות בסגירה; 11/11 בדיקות Node עברו. אימות חי הושלם ב־2026-11-01: המשתמש עדכן ל־15.3.1-beta.4, רענן את Gmail, בדק את ריחוף תגובת האימוג׳י ואישר שהחלונית מוצגת כראוי והתיקון עובד. זהו אישור המשתמש בסביבה החיה, נוסף לבדיקות האוטומטיות; אינו אישור להשלמת כלל בדיקות הבטא.

דוח קודם — beta.3

תיקוני beta.3

אבחון DOM בדף Gmail חי הראה ששכבת ::after המקורית תפסה את מלוא רוחב וגובה ההודעה, ובמצב cs-hold נשאר עליה חיתוך משולש מהזנב. הזנב הופרד לאלמנט ייעודי בגודל 8×13; שכבת Google נשארת ללא חיתוך. בנוסף נוספו טריגרים לחלוניות CSS בלבד ותוקנה התנגשות הקדימות בין cs-hold ל־cs-popup-raised.

19/19 בדיקות fixture עברו, כולל חמש בדיקות חדשות לציטוט, זנב עצמאי, חלונית במיקוד ללא שינוי DOM, קדימות בועה וניקוי בסגירה. 11/11 בדיקות Node עברו. ראיות: בדיקות beta.3. אימות ריחוף חי לאחר עדכון הסקריפט החדש עדיין לא בוצע.

המשתמש אישר עדכון ל־beta.3 ורענון Gmail. בבדיקה החיה לאחר העדכון זוהו 15 בועות ו־7 זנבות עצמאיים, ואפס שכבות ::after עם חיתוך משולש. כך אומת תיקון הציטוט במבנה Google האמיתי. פתיחת כרטיס המשתתפים בריחוף חי עדיין ממתינה; מיקוד המקלדת בכפתור אינו פותח את אותו כרטיס בממשק Google שנבדק.

קישור פרוזי נפתח בדפדפן והציג את פרופיל פרוזי. קובץ .zi הורד בהצלחה, נפתח כ־ZIP ונמצא בו manifest בגרסה 14.0.0. עותק זהה נשמר באתר תחת .zip עם download בשם Chat-Studio-14.0.0.zip. ניסיון הורדה באמצעות כלי הדפדפן המקומי החזיר כשל ללא סיבה מפורטת; אימות הארכיון והשם אינם טענה שההורדה דרך אותו כלי הושלמה.

לאחר הפריסה נבדקה גם הורדה ישירה מהאתר הציבורי: HTTP 200, סוג application/x-zip-compressed, ו־SHA256 זהה למקור. בדיקת הורדה אוטומטית באמצעות כלי הדפדפן הציבורי הסתיימה ב־timeout; הקישור והמאפיין download אומתו ב־DOM. שתי פעולות GitHub Actions, הבנייה והפריסה, הסתיימו בהצלחה.

בדיקות קודמות — beta.2

תאריך: 2026-11-01. זוהי גרסת בדיקה, לא אישור שחרור יציב.

בדיקות שהושלמו

  • npm run build: בנייה עצמאית, 99 נכסי SVG, אימות SHA256 של המקור ותחביר JavaScript.
  • npm test: 11/11 עברו. השוואה מלאה של 1,177 הגדרות עיצוב ו־688 רקעים למקור; אחסון ושינויי שדות מקבילים, טעינה מחדש, כשל שמירה, זיהוי חשבון, ולידציית גיבוי ומטא־דאטה. נבדק גם דחיית מקור חלון, origin, nonce ואינדקס חשבון שגויים בגשר Gmail.
  • Chrome, סביבת fixture מקומית תחת CSP ו־Trusted Types: 14/14 בדיקות עברו. כולל שורת שעה נפרדת, הסתרת המקור ושחזורו. האחסון כאן הוא מתאם GM מדומה, ולא התקנת Tampermonkey.
  • אותה בדיקת ריחוף נכשלת במקור: ההודעה הבאה מכסה את החלונית. בגרסה המומרת החלונית מעל ההודעה, והשכבות חוזרות למצב הקודם בסגירה.
  • כל 99 נכסי SVG הוצגו בדפדפן לצד המקור: 99 נטענו, אפס נכסים ריקים/כושלים. נבדק מדגם חזותי ונשמר צילום מלא להשוואה; זו אינה השוואת פיקסלים אוטומטית.
  • שינוי WhatsApp Dark בלשונית fixture שנייה עדכן את הלשונית הראשונה, כולל צבע הבועה. זהו סנכרון דרך מתאם GM המדומה; אינו מוכיח לבדו סנכרון Tampermonkey בין מקורות.
  • העלאת תמונת הדגמה דרך מנגנון הקובץ של המוצר, ציור בקנבס ושמירה לאחר רענון: עברו. נמצאה ותוקנה התרחבות רוחב הקנבס באזור grid/flex; רוחב המסמך נשאר בגבולות החלון.
  • עומס קצר, מצב חסכוני, 500 הודעות חדשות: מקור 527ms, המרה 657ms. מדידה מקומית יחידה לכל גרסה; אין להסיק ממנה ביצועים מובהקים או שימוש ממושך.
  • אתר התיעוד: הגלריה משנה תמונה, תמונות המסך נטענות, פריסה בטור אחד ברוחב 390px ללא גלילה אופקית. צילומי המוצר משתמשים בנתוני הדגמה בלבד.
  • חבילת תיקון נפרדת לתוסף המקורי: נבנתה ועברה בדיקת תחביר; טרם הותקנה כתוסף.

ראיות: המרה, מקור, עומס, צילומים.

בדיקות חיות וממצאים פתוחים

המשתמש אישר שהתקין beta.1 ידנית ב־Tampermonkey ורענן Chat, ובהמשך אישר שבדיקת העדכון הביאה אותו ל־beta.2 ושרענן Gmail. בדיקת DOM חיה אישרה את beta.2 הן ב־Google Chat העצמאי והן ב־iframe של Gmail Chat. בשניהם כתובת החשבון מזוהה; גשר Gmail פתר את הזהות החסרה שנמצאה ב־beta.1.

שינוי שפה מתוך חלונית Chat העצמאי הופיע בחלונית Gmail דרך האחסון האמיתי של Tampermonkey. השפה הוחזרה לעברית, ונשמרה לאחר רענון Chat. עיצוב WhatsApp שנבחר ב־beta.1 נשמר בעדכון. פרופילים מרובים, מועדפים ותמונות אישיות לא נבדקו במעבר גרסה החי, ולכן סעיף שימור כל המידע בשחרור היציב עדיין אינו מסומן.

שורת השעה המתקנת נוצרה בקוד החי עם display:flex, float:none ומרווח נפרד; הפרדתה מהטקסט ושחזור הזמן המקורי עברו בדיקת גאומטריה ב־fixture. אין צילום שיחות אמיתיות במאגר או באתר. בדיקת ריחוף אוטומטית על תגובה אמיתית לא בוצעה; השוואת הרגרסיה המתועדת היא בסביבת fixture.

GitHub Actions עבור ההעלאה הראשונה עבר בהצלחה. המאגר נפתח לציבור באישור מפורש, לאחר ש־GitHub דחה Pages במאגר פרטי עקב מגבלת תוכנית החשבון.

טרם אושרו במלואם: שימור כל סוגי המידע בעדכון, כל תרחישי Gmail Chat ותיבת הדואר, הפרדה בין מספר חשבונות אמיתיים, iframe מוגבל, תרחיש cold/warm מלא ושימוש ממושך. אין להשתמש בבדיקות fixture כאישור לאלה.

מגבלות ידועות

שינוי מקביל של אותו שדה פועל לפי הכתיבה האחרונה. רשימות מועדפים/תמונות אינן מתמזגות ברמת פריט. שמירת מספר מפתחות אינה טרנזקציה אטומית. קישורי תמונה חיצוניים כפופים למדיניות אתר Google. זהות חשבון לא ודאית גורמת לשימוש בעיצוב הכללי. אין גישה אוטומטית לאחסון התוסף המקורי; נדרש ייצוא יזום.

השחרור היציב חסום באמצעות release-checklist.json ו־scripts/release-gate.mjs עד השלמת הבדיקות החסרות.
