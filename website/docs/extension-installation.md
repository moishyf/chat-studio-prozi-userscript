# התקנת גרסת התוסף מקובץ ZIP

ההורדה המקורית שקושרה ממתמחים טופ מכילה את **Chat Studio 14.0.0**, כפי שמצוין ב־manifest.json. גרסה זו נפרדת מסקריפט Tampermonkey המבוסס על V15.3, ואינה כוללת את תיקוני הבטא שלו.

1. לחצו באתר על ״הורדת התוסף בקובץ ZIP״. הקובץ יישמר בשם `Chat-Studio-14.0.0.zip`; הסיומת כבר תוקנה מ־.zi ל־.zip ללא שינוי בתוכן הארכיון.
2. ב־Windows לחצו לחיצה ימנית על הקובץ ובחרו ״חלץ הכל״. בחרו תיקייה קבועה, ולא תיקייה שתימחק בסיום ההורדה.
3. ב־Chrome פתחו `chrome://extensions` והפעילו ״מצב מפתח״.
4. לחצו ״טעינת תוסף שלא נארז״ / Load unpacked. בחרו את התיקייה שחולצה ושבה נמצא `manifest.json`. אם יש תיקייה פנימית נוספת, פתחו אותה ובחרו בה.
5. כבו את סקריפט Chat Studio ב־Tampermonkey ואת כל עותק נוסף של התוסף, ורעננו את Gmail או Google Chat.

Chrome טוען את הקבצים מהתיקייה שבחרתם. אין למחוק אותה או להזיז אותה לאחר ההתקנה. בעדכון ידני יש להחליף את הקבצים, ללחוץ על רענון בכרטיס התוסף ולרענן גם את דף Chat. פרטי הטעינה והרענון מופיעים ב[מדריך הרשמי של Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).

אם הורדתם ישירות מהפורום וקיבלתם קובץ בסיומת `.zi`, אפשר לשנות את סיומתו ל־`.zip` לפני החילוץ. אין צורך בכך בכפתור ההורדה שבאתר שלנו.
