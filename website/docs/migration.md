# מעבר מ־V15.3

ל־Tampermonkey אין גישה לאחסון הפרטי של התוסף. אין העברה אוטומטית סמויה.

המסלול הפשוט: העתיקו קוד עיצוב מלשונית ההגדרות בתוסף וייבאו אותו בסקריפט. הקוד אינו מעביר תמונות או את כל הפרופילים.

לגיבוי מלא, משתמש מתקדם יכול להפעיל את tools/export-original.js בקונסול DevTools של content script של התוסף המקורי, לאחר שבחר במפורש בהקשר התוסף. יש לקרוא את הקוד לפני הפעלה. הוא קורא רק אחסון של Chat Studio ויוצר קובץ JSON מקומי. אין להפעילו בקונסול של אתר אקראי; ללא הקשר התוסף הפעולה תיכשל.

לאחר הייצוא: כבו את התוסף המקורי, התקינו את הסקריפט, פתחו הגדרות → ייבוא גיבוי, בחרו את הקובץ ורעננו. פרופילים לפי כתובת מייל נשמרים; פרופילים ישנים מסוג u0 אינם מופעלים על סמך האינדקס. הגדירו אותם מחדש בחשבון מזוהה כדי לא לערבב חשבונות.

כלי הייצוא לא הופעל מול האחסון הפרטי בדפדפן זה. יש לבדוק אותו ואת המיגרציה המלאה לפני מחיקת המקור. שמרו עותק גיבוי נפרד, ובדקו תמונות, מועדפים ופרופילים לאחר המעבר.
